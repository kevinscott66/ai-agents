## Подтверждённые проблемы и исправления

| Область | Проблема | Исправление и проверка |
|---|---|---|
| Микрофон | Ответ системного разрешения после Stop/background мог включить запись заново | Поколение запроса проверяется до/после ожиданий, повторный старт блокируется; Swift build |
| Чат | Ошибка отменённого запроса A могла сбросить busy/error нового B | Идентификатор операции + проверка отмены; исполняемый Swift regression |
| Восстановление | Изменение сервера ломало проверку ранее отправленного запроса | Poll использует сохранённый сервер задания; Swift regression |
| Подключение | Редактирование адреса меняло активный сервер до успешного pairing | Черновик настроек и блокировка полей во время подключения |
| Keychain | Delete-before-add терял рабочий ключ при неудачном сохранении | SecItemUpdate, Add только при not-found; код скомпилирован, реальные ошибки Keychain не инъектировались |
| HTTP iPhone | Ответ загружался целиком без ограничения памяти | Поток до 4 MiB, общий network resource timeout 30s; fixture на точной границе/переполнении |
| Native protocol | Любой неожиданный статус считался завершением; ID ответа не сверялся | Проверка ID/статуса/80 ответов/8000 UTF16 и pairing token; Swift fixture |
| Native API | Тело неавторизованного запроса читалось до отказа; slow body без дедлайна | Авторизация до чтения, 16 KiB и 5s, cancellation; tests |
| Native jobs | Синхронное исключение lead оставляло job running | Вызов в Promise continuation, терминальное error; regression с новым последующим заданием |
| Pairing | Текущий device credential мог выпустить новый ключ через /pair_native | Выпуск ключа только из доверенного Telegram transport; regression |
| Уведомления | Отзыв Telegram allowlist не останавливал уведомления при сохранённом MAC ACL | Общая функция владельца для native и alerts; regression отзыва |
| Mac | Cancel/stop/обрыв соединения не останавливал personal-команду; последовательные open могли выйти за таймаут моста | Общий AbortController и 20s дедлайн, SIGKILL дочернему процессу, проверка перед следующим запуском; mock и настоящий /bin/sleep cancellation |
| Codex | Ограничения native tools доказаны для 0.149.0, но принималась любая версия/бинарник из PATH | Абсолютный путь и точная версия до inference; subprocess regression |
| Codex usage | Отсутствующая/последняя без newline completion обходила учёт расхода | Потоковый учёт, обязательное единственное completion; regressions missing/duplicate/unterminated |
| Codex ресурсы | Размер файла проверялся после чтения; MIME и суммарный размер картинок не проверялись | Ограниченное чтение, MIME whitelist, общий 20 MiB; oversized subprocess regression |
| Интерфейс | Маленькая зона основной кнопки и перезапись draft старой диктовкой | 44 pt target, остановка диктовки при выборе команд; сохранён Liquid Glass / ChatGPT-like стиль |

## Границы результата

Нет утверждения, что проверены все возможные атаки. Аудит сфокусирован на новой версии и её границах с существующим dispatcher. Не запускались реальные заказы, переводы, публикации или операции с рабочими серверами. Системные окна микрофона/Calendar и реальный отказ Keychain требуют device-проверки. Внешняя автоматизация UI через CUA в этой сессии не запустилась; статические снимки симулятора проверяются отдельно.

Codex по-прежнему требует авторизации, места для CLI и live model smoke. Жёсткий API max_tokens в CLI не воспроизводится — это явно описано в `docs/inference-providers.md`. Подготовка patch/unsigned IPA не означает deployment или возможность установки без подписи.
