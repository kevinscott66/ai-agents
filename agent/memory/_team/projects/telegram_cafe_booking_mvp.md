# Telegram-бот бронирования столиков в кафе (MVP)

## Описание
MVP Telegram-бота для приёма бронирования столиков в кафе.

## Область MVP
- Бот принимает бронь: дата, время, кол-во гостей, имя, телефон
- Проверяет доступность слотов
- Подтверждает бронь пользователю
- Уведомляет администратора кафе
