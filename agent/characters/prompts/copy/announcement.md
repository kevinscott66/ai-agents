# Announcement Template

## Purpose
Для анонсов новых функций, релизов, обновлений, официальных объявлений.

## Tone
Официальный, но не канцелярский. Энергичный, позитивный. Фокус на пользе.

## Structure
1. **Заголовок** — что именно анонсируем (конкретно, без абстракций)
2. **Что это даёт** — польза для пользователя в 1-2 предложениях
3. **Ключевые особенности** — 2-4 буллета с конкретикой
4. **Доступность** — когда, где, как получить
5. **Call-to-action** — конкретное действие

## Guidelines
- Без "мы рады представить" — сразу к сути
- Цифры и факты вместо эпитетов
- Избегать "революционный", "уникальный", "инновационный"
- Максимум 150 слов для Telegram-постов

## Example
**Новый API для управления командами**

Теперь можно создавать и настраивать агентские роли через REST API вместо ручного редактирования конфигов.

Ключевые возможности:
• Создание custom ролей за 30 секунд
• Настройка permissions через веб-интерфейс  
• Автоматическое развёртывание без перезагрузки
• Интеграция с существующими workflow

Доступно в версии 2.1, документация: /docs/api/roles
