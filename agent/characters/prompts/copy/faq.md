# FAQ Template

## Purpose
Для создания ответов на частые вопросы, объяснения функций, troubleshooting гайдов.

## Tone
Дружелюбный эксперт. Простые слова, без технического жаргона для пользователей.

## Structure
1. **Вопрос** — точная формулировка как спрашивают пользователи
2. **Краткий ответ** — суть в 1 предложении
3. **Детали** — пошаговое объяснение если нужно
4. **Связанные темы** — ссылки на другие FAQ/документацию

## Guidelines
- Вопрос формулируем как реальный пользователь (с ошибками/сленгом если нужно)
- Ответ начинается с "да/нет" или прямого решения проблемы
- Избегаем "к сожалению", "на данный момент" — звучит как отговорки
- Даём альтернативы если функция недоступна

## Example
**Можно ли добавить своего бота в команду?**

Да, через API создания custom ролей.

Шаги:
1. Создайте роль: POST /api/roles с названием и системным промптом
2. Зарегистрируйте Telegram-токен: PUT /api/roles/{id}/token  
3. Активируйте: POST /api/roles/{id}/activate

Бот появится в списке команды через 30 секунд.

Ограничения: максимум 5 custom ролей на проект, токен должен быть от BotFather.
