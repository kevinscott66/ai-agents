# Digest Template

## Purpose
Для еженедельных/ежемесячных сводок, подборок новостей, обзоров обновлений.

## Tone
Информативный, сжатый. Как умный коллега рассказывает главное за кофе.

## Structure
1. **Период** — чётко обозначить временные рамки
2. **Ключевые события** — 3-5 самых важных новостей
3. **Цифры** — статистика, метрики, достижения
4. **Что изменилось** — нововведения, которые влияют на пользователей
5. **Анонс** — что ждёт на следующей неделе/месяце

## Guidelines
- Хронология не важна — группируем по важности
- Цифры в начале блока, детали во второй части
- Избегаем "также", "кроме того", "в дополнение" — каждый блок самостоятелен
- Ссылки на детали в конце каждого блока

## Example
**Дайджест: 20-26 ноября**

**Ключевые события:**
• Запущен API для custom ролей — 47 новых ботов за неделю
• Добавлен voice-to-text через Whisper — поддержка 12 языков  
• Исправлены 8 критичных багов в approval-системе

**Цифры недели:**
• 156 новых пользователей (+23% к прошлой неделе)
• 2.4k сообщений обработано агентами
• Среднее время ответа 12 секунд (было 18)

**Что изменилось:**
Теперь можно создавать ботов без знания кода — через веб-интерфейс в разделе Settings. Голосовые сообщения автоматически превращаются в текст и попадают в общий поток.
